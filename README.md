📋 Quadro Kanban

Uma aplicação web simples, intuitiva e funcional para gerenciamento de tarefas do dia a dia, utilizando a metodologia Kanban.

⚠️ Nota: Este é um projeto demonstrativo criado especialmente para fins de apresentação.

🔗 Acesse o projeto online: https://projeto-kanbann.web.app/

📌 Sobre o Projeto

O Quadro Kanban foi desenvolvido para demonstrar o fluxo visual de gerenciamento de tarefas, ajudando na organização de atividades cotidianas e projetos pessoais de forma clara e ágil.

Com uma interface limpa e organizada, a aplicação permite acompanhar o fluxo de trabalho dividindo as tarefas nas seguintes colunas:

🔴 A Fazer: Atividades pendentes que precisam ser iniciadas.

🟡 Em Andamento: Tarefas em execução no momento.

🟢 Concluído: Atividades finalizadas.

🚀 Funcionalidades

Criação de Tarefas: Adicione novas tarefas com título e descrição rápida.

Movimentação entre Colunas: Altere o status das tarefas à medida que o trabalho avança.

Contador Dinâmico: Visualize a quantidade de itens em cada etapa em tempo real.

Interface Responsiva: Design adaptado para telas de computadores e dispositivos móveis.

🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

HTML5: Estrutura da aplicação.

CSS3 / Flexbox: Estilização e layout responsivo.

JavaScript (ES6+): Lógica da aplicação e manipulação do DOM.

Firebase Hosting: Hospedagem e deploy da aplicação na nuvem.
